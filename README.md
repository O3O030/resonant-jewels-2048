# 晶弦共鳴 · Resonant Jewels 2048

A standalone React + Vite 2048-style gemstone merging game.

## Game progression

2 → 4 → 8 → 16 → 32 → 64 → 128 → 256 → 512 → 1024 → 2048 → 4096 → …

2048 is a major milestone, not the end of the game. Players can continue merging beyond 2048.

## Run locally

```bash
npm install
npm run dev
```

## Build for Vercel

```bash
npm run build
```

Vercel settings: Framework Preset **Vite**, Build Command `npm run build`, Output Directory `dist`.
